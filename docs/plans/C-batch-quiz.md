## Q4 — What happens when a waystone is destroyed? (T4)

- [ ] **Blocks NEW placement only** (default) — existing buildings out there survive;
      you just can't expand from a dead stone until it's rebuilt. Simple, forgiving.
- [ ] **Buildings beyond it go dark** — disconnected structures stop contributing
      income/territory until the chain is restored. Harsher, more strategic.
- [x] **Full collapse** — disconnected buildings start decaying. Maximum stakes,
